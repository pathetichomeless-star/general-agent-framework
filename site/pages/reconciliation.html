UNKNOWN & reconciliation

A lost response leaves two separate questions

UNKNOWN ≠ FAILED

The external system may apply a write even when its response never arrives. A timeout tells the caller that confirmation is missing; it does not prove that the change failed.

COMMAND TRUTH = UNKNOWN

UNKNOWN

The command did not receive a confirmation.

EXTERNAL RECONCILIATION VERDICT = MATCHED (derived)

MATCHED (derived)

A fresh, usable external observation agrees with the intended change.

MATCHED does not become command SUCCESS. A reconciliation verdict is derived from external evidence. It does not rewrite the original uncertainty or declare the command completed.

Why blind retry is unsafe

If the first write already happened, repeating it can duplicate the side effect. The technical demo refuses a blind redispatch of an UNKNOWN command.

A conditional redispatch requires valid, active operator-confirmed configuration asserting both that the provider honors the same idempotency key and that repeating the operation is safe. The Framework records that operator assertion; it does not guarantee third-party behavior.

No universal exactly-once guarantee or guaranteed third-party idempotency is claimed. The demo's observed ledger count belongs to that controlled synthetic run.

Observe, check freshness, derive

  1. Read authoritative external state

    Use a governed observation of the external object instead of interpreting a timeout as failure.

  2. Check that the observation is usable

    Freshness matters. Stale or unusable evidence cannot be counted as a match.

  3. Derive a separate verdict

    In the technical demo, an observation without a usable freshness window gives UNOBSERVABLE; a fresh matching observation gives MATCHED (derived). Command truth remains UNKNOWN.

  4. Keep the evidence inspectable

    Retain observations and audit records. Approval-task evidence-chain verification is scoped to that task, not the complete audit database.

Other conceptual verdicts are UNOBSERVED and DIVERGED. The public technical demo exercises UNOBSERVABLE and MATCHED (derived), not every vocabulary entry.
