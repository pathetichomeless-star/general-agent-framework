# Commercial Access

This repository is the **public showcase** for the General Agent Framework. The framework itself
is a separate commercial product, and its implementation is private.

## What this public repository contains

- product documentation under [`docs/`](docs/)
- a conceptual architecture overview
- the public demonstration under [`demo/`](demo/) — deterministic, synthetic data only
- captured screenshots and visual assets under [`assets/`](assets/)
- controlled, non-production examples

## What this public repository deliberately does NOT contain

- the commercial framework implementation source
- the full private test suite
- customer-specific bundles
- private licensing and delivery arrangements

## How commercial access works

Access to the commercial framework is provided under a **separate, private licence**. Public
availability of this showcase grants no rights to the commercial framework — it is public to
view, not open source. See [`LICENSE`](LICENSE).

**No fixed price is published.** Pricing and terms are handled privately as part of a commercial
licence discussion. Exact source and artifact delivery depends on that private commercial
agreement: only the components identified for a given transaction are delivered and licensed.
