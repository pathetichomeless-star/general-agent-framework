# EXPECTED_FLOW — 金路径分镜 Golden Path

确定性故事：从询价到审计回放。所有数字为合成数据。
Deterministic story from inquiry to audit review. All figures are synthetic.

## S0 · 登录 Login（0:00）

- 以 `sales`（李婷·销售）登录 → 工作台显示销售视角；右上角可切 English。
- 页面顶部常驻模式横幅：**公共模拟模式**。

## S1 · AI 起草报价（0:30）

- 报价 → 新建报价：客户“美驰汽车零部件”、产品“法兰 FLG-125”、数量 2000、折扣 8%。
- 点 **AI 起草报价**：按价格本目录价 ¥46 计算，成交价 ¥42.32，合计 **¥84,640**，并给出计算理由。

## S2 · 折扣审批（结构性闸门）（1:00）

- **提交报价**：折扣 8% > 5% 阈值 → 后端自动生成审批请求 `APPR-xxxx`，报价进入“待审批”。
- 关键点：销售**无法**自批（职责分离由后端强制，不是提示）。

## S3 · 老板审批（1:40）

- 切换 `owner`（林文昊）：工作台“待我审批”≥1 → 审批页通过该报价（附意见）。
- 报价状态 → 已批准；证据即时写入审批任务证据链。

## S4 · 订单确认（2:10）

- 切回 `sales`：报价详情 → **接受报价并生成订单** → 自动生成订单 `SO-0148`（草稿）。
- **确认订单**：总额 > ¥50,000 → 再次进入老板审批 → 通过后“已确认”。

## S5 · AI 物料检查 → 缺料（2:40）

- 订单详情 → **AI 物料与产能检查**：BOM(SS304 0.13kg/件)×2000 = 260kg，库存 180kg → **缺 80kg**。
- AI 建议紧急采购 120kg（打包步进、含 ETA 3 天）→ 自动生成**紧急采购审批请求**（建议≠执行）。

## S6 · 老板批准紧急采购（3:20）

- `owner` 审批通过 → 系统生成仓库任务“紧急采购入库”，并通知仓库/厂长。

## S7 · 生产执行（3:40）

- 切换 `factory`：订单详情 → **创建生产工单**（FLG-125 × 2000，交期 2026-10-20）→ 工单 `PO-xxxx` 已计划。
- **下达工单** → 自动生成仓库“领料”任务；订单进入“生产中”。
- （生产看板上还有种子逾期工单 `PO-2026-0092`——哨兵 Job 会自动生成处置任务与紧急通知。）

## S8 · 仓库领料 → 先失败，后成功（4:20）

- 切换 `warehouse`：任务收件箱 → 领料。**若紧急物料未入库：系统诚实报“库存不足”**。
- 执行紧急采购入库（+120kg）→ 再领料：SS304 扣减 260kg，库存流水留痕。
- 厂长报工 → **完工**；成品待入库，订单变为“待发货”。

## S9 · 发货：UNKNOWN（5:00）

- `sales` 订单详情 → **申请发货** → 生成发货单。
- 切 `warehouse` → **执行发货**：受治理外部动作登记并**只执行一次**；模拟承运商“已写入但响应丢失”→ 界面显示 **命令真相 = UNKNOWN**（不猜测、不改写）。
- 再点执行 → **盲重试被拒绝**（框架级守卫的演示语义）。

## S10 · 对账：匹配（推导）（5:40）

- 发货详情 → **对账**：通过治理读取边界查看承运商账本（新鲜的权威读）→ 与已批准内容一致 → 判定 **匹配 MATCHED（推导）**。
- 两条真相并列显示、**永不合并**：命令真相保持 UNKNOWN；外部判定是推导值，不是“发送成功”。

## S11 · 审计回放（6:20）

- 切 `owner` 或 `admin` → 审计记录 → 打开 `SO-0148` 时间线：报价→审批→订单→生产→领料→完工→发货→对账全程可回放。
- **验证证据链**：审批任务证据域验证通过；其余审计记录如实标注“保留可审计（不入链）”。
- （演示模式）对种子副本篡改一条记录 → 验证**失败**变红。

## S12 · 管理员视角（7:20）

- `admin` 登录：无任何业务菜单与业务按钮，仅用户与角色 + 审计——治理边界即产品行为。
