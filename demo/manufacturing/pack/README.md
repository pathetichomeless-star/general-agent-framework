形式在私有侧绑定到框架的注册与发现能力（应用→业务能力→授权→网关→证据链）。

This directory is a placeholder. In Licensed Framework Mode, the manufacturing
domain is bound through the framework's Domain Pack / customer-application
composition in the PRIVATE adapter package. No pack code ships in this public
repository.
