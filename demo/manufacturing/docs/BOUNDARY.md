# Boundary — 公共/私有边界与守卫

## 三类分类

| 类别 | 内容 |
|---|---|
| **公共演示安全** | 本目录全部应用代码（仅依赖 framework_port）、确定性模拟后端、合成种子、文档、截图、双语术语表、契约测试与边界守卫 |
| **私有商业框架** | 商业框架实现源码、私有测试套件、发布/验收证据、私有交付工件、许可条款、持牌后端适配器实现——一律不进公共仓库 |
| **模拟而非集成** | 承运商/物流（进程内确定性账本）、邮件（界面内模拟信箱）、MES 报工（人工确认模拟）、供应商/采购系统、客户门户、支付 |

## 公共代码禁止项（守卫测试强制）

1. 不得 import 或动态加载商业框架的任何模块；
2. 不得引用框架相关环境变量（持牌模式由私有适配器自行解析框架）；
3. 不得出现私有目录名、私有绝对路径；
4. 不得出现框架内部类/存储/服务/组合/契约名；
5. 不得使用任何下划线私有框架 API（助手消息持久化为 demo 本地实现；持牌模式下该能力如实标注 LIMITED）；
6. 不得复用/机械复刻私有实现逻辑（模拟后端从规格与公共声明独立编写，评审含来源检查）；
7. 无网络、无凭据、仅合成数据。

守卫执行：`tests/test_boundary.py` 对 `demo/manufacturing/**` 全文件扫描禁用模式 + AST import 白名单检查。

## 命名与措辞纪律

- 两个真相轴：命令真相（UNKNOWN）与外部判定（匹配（推导））——并列展示，永不合并、永不改写。
- 哈希链验证只声称审批任务证据域；其余审计记录称“保留可审计”。
- 公共模拟模式永不声称商业框架执行了任何动作；README/Manifest 的双模式措辞必须成对出现。
- 定位句不得孤立引用；复现必须携带完整 "What this demo is not" 限定。
- 只用通用系统标签（承运商/仓库系统），无第三方品牌。
